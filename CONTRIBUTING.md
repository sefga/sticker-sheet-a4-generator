# Руководство по участию в разработке (Contributing to StickerFit)

Спасибо за интерес к развитию проекта **StickerFit**!  
StickerFit — это открытый инструмент (MIT) для автоматической раскладки наклеек на листах A4 с физической точностью в миллиметрах.

---

## 🧭 Принципы проекта

1. **Client-Side First**: вся обработка изображений, расчет геометрии и сборка PDF происходят исключительно в браузере пользователя на клиенте.
2. **Физическая точность (1:1)**: точность в миллиметрах непререкаема. Любые изменения в `layoutEngine` или `pdfGenerator` обязаны сопровождаться тестами геометрии.
3. **Простота и скорость**: интерфейс должен позволять получить готовый PDF за 30–60 секунд с момента открытия страницы, без обязательных регистраций и рекламы.
4. **Zero Bloatware**: мы избегаем тяжелых зависимостей.

---

## 🛠️ Локальная разработка

### Требования:
- Node.js >= 18
- Google Chrome (для запуска тестов агентов-критиков Puppeteer)

### Команды:
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки (Vite)
npm run dev

# 3. Запуск модульных и регрессионных тестов (Vitest)
npm test

# 4. Проверка типов и сборка
npm run build

# 5. Полный цикл валидации качества (тесты + 4 браузерных агента-критика)
npm run eval
```

---

## 🧪 Требования к тестам

- Если вы добавляете новый функционал раскладки, напишите тест в `src/layout/layoutEngine.test.ts` или `tests/printCorrectness.test.ts`.
- Если вы добавляете локализуемые строки, обязательно внесите их в `src/i18n.ts` для обоих языков (`ru` и `en`).
- Перед отправкой Pull Request убедитесь, что команда `npm run eval` завершается со 100% успешным статусом (все критики $\ge 95$ баллов).

---

## 🔀 Процесс Pull Request

1. Сделайте Fork репозитория и создайте тематическую ветку: `git checkout -b feature/my-feature`.
2. Зафиксируйте изменения: `git commit -m "feat: description"`.
3. Убедитесь, что все тесты проходят: `npm test && npm run build`.
4. Отправьте ветку в свой fork и откройте Pull Request в ветку `main`.
